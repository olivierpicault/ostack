# ostack

Olivier's rules and skills for Claude Code.

## Install

```bash
claude plugin marketplace add olivierpicault/ostack
claude plugin install ostack@ostack
```

Restart Claude Code.

## Update

```bash
claude plugin marketplace update ostack
claude plugin update ostack@ostack
```

Restart Claude Code.

If the update does not pick up the latest commit, reinstall:

```bash
claude plugin uninstall ostack@ostack
claude plugin install ostack@ostack
```
